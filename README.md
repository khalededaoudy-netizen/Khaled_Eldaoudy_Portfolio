## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (tested on Node 24)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/khaledeldaoudy/khaled-eldaoudy-portfolio.git

# Enter the directory
cd khaled-eldaoudy-portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Production Build

```bash
npm run build
```

The optimized static assets will be output to the `dist/` directory, ready to deploy.

## 🌐 Deployment to Vercel

1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of Khaled Eldaoudy portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/khaled-portfolio.git
   git push -u origin main
   ```
2. Import the repository into [Vercel](https://vercel.com).
3. The build command `npm run build` and output directory `dist` are pre-configured.
