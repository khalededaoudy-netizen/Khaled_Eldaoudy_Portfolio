# 🏛️ موقع المهندس خالد الداودي | Editorial Luxury Engineering Portfolio

الموقع الشخصي والبورتفوليو الهندسي الرقمي للمهندس **خالد حمدي الداودي** — طالب بالفرقة الخامسة بهندسة الميكاترونكس بجامعة الزقازيق الأهلية (سنة التخرج المتوقعة: 2027)، المتخصص في البرمجيات الدقيقة (Embedded Firmware)، ونظم التحكم المغلقة (Control Loops)، والروبوتات الذاتية (Autonomous Robotics).

الموقع مصمم وفق هوية بصرية فاخرة **"Editorial Luxury"** تجمع بين فن الإخراج الصحفي الراقي والجماليات الهندسية المتقدمة، ومبني بأحدث معايير الويب الخفيفة والسريعة.

---

## ✨ المميزات والهوية التقنية

* **الهوية البصرية الفاخرة (Editorial Luxury):**
  * لوحة ألوان مستوحاة من فخامة حجر الأوبسيديان الداكن (`#090909`) مع لمسات هندسية من ذهب الشامبين (`#C6A66B`).
  * طباعة تحريرية كلاسيكية معاصرة تمزج بين خط `Cormorant Garamond` للعناوين الملكية وخط `Inter` للقراءة السلسة وخط `IBM Plex Sans Arabic` للنصوص العربية.
  * لوحة تحكم حركية (Kinematics HUD) ثلاثية الأبعاد تفاعلية مدعومة بمكتبة Three.js.
* **بنية برمجية معيارية خفيفة (Vanilla Web Standards):**
  * بنية نقية باستخدام HTML5 و CSS3 المعياري (Custom Properties) و JavaScript ES Modules.
  * صفر أطر عمل ثقيلة وبدون تعقيدات Bundlers، مما يضمن تحميل لحظي وتجربة مستخدم فائقة السرعة.
* **دعم كامل للغتين (Bilingual EN / AR) وتنسيق RTL / LTR:**
  * تبديل فوري وسلس بين الإنجليزية والعربية دون إعادة تحميل الصفحة.
  * توافق تام مع اتجاه القراءة من اليمين إلى اليسار (RTL) للغة العربية مع ضبط الخطوط والظلال والمسافات بدقة.
* **عزل كامل لمجلد الإنتاج (`dist/`):**
  * مسار بناء آلي يعزل ملفات الإنتاج العامة داخل مجلد `dist/` ويحجب أي تقارير داخلية أو ملفات تطوير عن الشبكة العامة.

## ⚡ 1. التشغيل المحلي (Local Development)

يعتمد الموقع على تحميل بيانات المشاريع والمحتوى بصيغة JSON عبر دوال `fetch()` في JavaScript. لتشغيل الموقع محلياً وتفادي قيود CORS في المتصفح:

### باستخدام Python:
```bash
python -m http.server 8080
```
ثم افتح الرابط: `http://localhost:8080`

### باستخدام Node.js:
```bash
npx serve .
```

## 🏗️ 2. دورة البناء والتحقق (Build Pipeline)

المشروع مزود بأمر بناء متكامل يقوم بالتحقق من البيانات أولاً ثم إنشاء النسخة الإنتاجية:

```bash
npm run build
```

يقوم هذا الأمر بـ:
1. **فحص سلامة البيانات (`scripts/validate-data.js`):** فحص 140 عنصراً بيانياً عبر 7 ملفات JSON للتأكد من اكتمال الترجمات الإنجليزية والعربية ووجود كافة ملفات الوسائط.
2. **تجهيز مجلد التوزيع (`scripts/build-dist.js`):** تنظيف وإنشاء مجلد `dist/` الإنتاجي ونسخ الأصول العامة فقط (`index.html`, `404.html`, `css/`, `js/`, `data/`, `assets/`, `robots.txt`, `sitemap.xml`) مع التأكد أمنياً من عدم تسريب أي ملفات خاصة أو تقارير داخلية.

## 🚀 3. خطوات النشر السحابي عبر Netlify

المستودع مهيأ بالكامل للنشر التلقائي عبر **Netlify** باستخدام ملف التكوين [`netlify.toml`](./netlify.toml):

1. ادخل إلى حسابك على [Netlify](https://app.netlify.com/).
2. اختر **"Add new site" > "Import an existing project"**.
3. اختر مزود Git (GitHub) وحدد مستودع: `khalededaoudy-netizen/Khaled_Eldaoudy_Portfolio`.
4. سيتعرف Netlify تلقائياً على إعدادات البناء الموجودة في `netlify.toml`:
   * **Build Command:** `npm run build`
   * **Publish Directory:** `dist`
5. اضغط **"Deploy Site"**. سيقوم Netlify بتشغيل البناء ونشر المجلد المعزول تلقائياً وتفعيل شهادة الأمان SSL ورؤوس الحماية الأمنية.

## 📁 4. إدارة المحتوى والبيانات

كافة نصوص وبيانات الموقع مفصولة بالكامل داخل مجلد `data/` لسهولة التعديل دون لمس كود الواجهة:

* `data/profile.json`: البيانات الشخصية، النبذة، روابط التواصل، وسنة التخرج (2027 - الفرقة الخامسة).
* `data/projects.json`: المشروعات الهندسية وتفاصيلها الفنية وتقنياتها المستخدمة.
* `data/skills.json`: المهارات والعتاد والأدوات البرمجية مقسمة حسب التخصص.
* `data/competitions.json`: إنجازات المسابقات (مثل المركز الثاني في RoboSoccer).
* `data/certifications.json`: الشهادات والاعتمادات الرسمية.
* `data/training.json`: سجلات التدريب الصناعي والمهني (400+ ساعة تدريبية).
* `data/leadership.json`: الأنشطة القيادية والتمثيل الجامعي.
* `data/i18n.json`: قاموس الترجمات للواجهة الثنائية (English & Arabic).

## 🔧 5. التخصيص ونموذج التواصل

* **نموذج التواصل (Formspree):**
  الموقع مربوط مسبقاً بنموذج Formspree مع تفعيل حماية Honeypot لمكافحة الرسائل المزعجة. لتعديل معرّف النموذج مستقبلاً، حدّث السطر 9 في `js/config.js`:
  ```javascript
  FORMSPREE_ENDPOINT: "https://formspree.io/f/your_form_id",
  ```
* **السيرة الذاتية (CV):**
  يقع ملف السيرة الذاتية القابل للتحميل في: `assets/cv/Khaled_CV.pdf`.

## 🧪 6. الأوامر المساعدة

* `npm run build`: التحقق من البيانات وتوليد نسخة الإنتاج المعزولة في `dist/`.
* `npm run validate`: فحص اكتمال نصوص اللغتين وتواجد مسارات الملفات دون بناء.
* `npm run sync-images`: فحص ومزامنة مجلدات الصور مع ملفات الـ JSON.
* `npm run optimize`: تحويل الصور الأصلية إلى صيغ WebP الحديثة.
