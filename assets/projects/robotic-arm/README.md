# projects / robotic-arm

## English Instructions
- **Required Content:** 3-6 clear photos of the Robotic Arm (Pick & Place): mechanical structure, servo linkages, Arduino wiring, gripper, picking/placing demo.
- **Naming Rule:** Lowercase English only, no spaces, numbered sequentially (e.g., photo-01.jpg, photo-02.jpg).
- **Cover Image:** The primary/best image to display as the thumbnail or cover MUST be named cover.jpg.
- **Recommended Minimum Size:** 1200px wide (JPG, PNG, or WebP). High clarity and good lighting.
